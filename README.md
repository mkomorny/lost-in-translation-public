# Lost in Translation Telephone

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Multi-language roundtrip semantic drift probe using the Belebele 122-language parallel dataset.

---

## Overview

`lost-in-translation` provides standardized capabilities across conversational AI platforms:
- Chain-translates text through diverse and obscure world languages back to English.\n- Draws language samples from the 122-language Meta Belebele parallel corpus on Drive B.\n- Visualizes step-by-step semantic drift, idiomatic loss, and humorous mangling.\n- Measures translation fidelity and linguistic robustness of language models.\n- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.

---

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\lost-in-translation`
- **Claude**: `C:\Users\<you>\.claude\skills\lost-in-translation` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\lost-in-translation` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\lost-in-translation` (NTFS Junction)
